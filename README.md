# Anastasia YouTube — Android

Ένα κουμπί που επιπλέει πάνω από την εφαρμογή YouTube. Ένα πάτημα
αλλάζει τραγούδι ή ολόκληρη τη μουσική.

Φτιάχτηκε για την Αναστασία, που έχει αυτισμό και αγαπάει τη μουσική
αλλά δεν μπορεί να χειριστεί το YouTube μόνη της.

**Δημιουργός:** Απόστολος Μακρυγένης
**Αφιερωμένο στην Αναστασία**

## Πώς δουλεύει

- **Αλλαγή τραγουδιού** — στέλνει στο YouTube την εντολή «επόμενο»,
  την ίδια που στέλνει το κουμπί ενός ασύρματου ακουστικού.
- **Αλλαγή μουσικής** — ανοίγει το YouTube σε τυχαίο τραγούδι άλλης
  λίστας, διαλεγμένης με βάρη ανά κατηγορία.
- **Μαθαίνει** — όσες λίστες προσπερνάει συστηματικά παίζουν σπανιότερα.

Η λογική του κουμπιού είναι ίδια με το πλήκτρο END της έκδοσης για
υπολογιστή: πάτημα μετά από Χ δευτερόλεπτα αλλάζει τραγούδι, νωρίτερα
αλλάζει μουσική, με ρυθμιζόμενη ανοχή ενδιάμεσα.

## Άδειες που ζητάει

| Άδεια | Γιατί |
|---|---|
| Εμφάνιση πάνω από άλλες εφαρμογές | Για να φαίνεται το κουμπί πάνω στο YouTube |
| Πρόσβαση σε ειδοποιήσεις | Για να στέλνει το «επόμενο τραγούδι» στο YouTube |
| Διαδίκτυο | Για να βρίσκει τα τραγούδια κάθε λίστας |

Καμία από αυτές δεν στέλνει δεδομένα πουθενά.
